# Denote 프로젝트 체크리스트

## GitHub Pages에 올리기
1. GitHub에서 새 저장소를 만듭니다.
2. 이 폴더의 파일 3개(index.html, checklist_library.csv, README.md)를 저장소 최상위에 올립니다.
3. 저장소의 **Settings → Pages**에서 배포 소스를 **Deploy from a branch**, 브랜치를 **main**, 폴더를 **/(root)**로 설정하고 저장합니다.
4. 잠시 기다린 뒤 Pages가 표시하는 주소로 접속합니다.

## 현재 동작
- index.html은 별도 서버 없이 GitHub Pages에서 실행되는 단일 페이지입니다.
- 프로젝트, 분류 선택, 완료 체크, 진행률은 해당 브라우저의 로컬 저장소에 보관됩니다. 브라우저/기기/사용자가 다르면 데이터가 공유되지 않습니다.
- checklist_library.csv는 체크리스트 라이브러리의 편집용 데이터 내보내기입니다. 현재 페이지는 CSV를 자동으로 읽지 않고, 실제 표시 항목은 index.html 안의 LIBRARY 데이터입니다. CSV 내용을 수정해도 페이지에 자동 반영되지는 않습니다.
- CSV 열: ID, 검수 항목, 세부 내용, 브랜드, 품목, 소재, 패키지. 분류값 여러 개는 | 로 구분하며, 빈 칸은 공통 항목입니다.

## 필터 방식
프로젝트에서 브랜드·품목·소재·패키지를 선택하면, 라이브러리 항목 중 지정된 분류가 모두 일치하는 항목만 표시합니다. 특정 분류를 지정하지 않은 항목은 그 분류에 관계없이 표시됩니다.
